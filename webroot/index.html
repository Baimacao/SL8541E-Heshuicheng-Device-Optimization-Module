# 状态为开机快照，点模块卡片「操作」按钮刷新
[?] 模块刷进去没反应 / 找不到模块

> 确认 Root 管理器是 APatch / Magisk v20.4+ / KernelSU

> 重启设备（模块必须重启才生效）

> 打开管理器 → 模块 → 检查本模块是否在列表且已启用

> 如果安装时提示"文件不完整"，重新下载 zip

[?] 状态显示"未生效"

> 先重启一次，很多东西是开机时才写入的

> 重启后仍然未生效，看日志：

cat /data/adb/modules/SL8541E_Config_Fix/fix.log

> 检查是否有其他模块冲突（尤其 Hc_memory、tcpboost）

> 确认设备是 SL8541E / SC9832E + 和顺成方案

[?] 充电还是很慢

> 模块把输入上限拉到 3A，但充电器功率才是关键

> 5V 1A 充电器 → 实际最多 890mA

> 5V 2A 充电器 → 实际能到 1500mA+

> 不要用电脑 USB 口（永远 500mA）

> 充电温度健康范围：34~42°C

[?] GitHub 还是打不开

> 检查 hosts 是否挂载：

cat /system/etc/hosts | grep github

> 动态守护会每 30 分钟检测一次，可能需要等

> 手动强制刷新：重启设备

> 如果 IP 全部失效，编辑 system/etc/hosts 换新 IP

[?] 动画不流畅 / 卡顿

> 本模块恢复了 SurfaceFlinger 的背压与 vsync 同步，动画完整了，但 A53 渲染能力有限

> 觉得卡可以进 设置 → 开发者选项 → 动画缩放 手动改小

> 或者改回厂商原始值（省电优先）

> 编辑 system.prop：

debug.sf.disable_backpressure=1

debug.sf.latch_unsignaled=1

[?] 音频有电流声 / 高品质音乐播不了

> 本模块不碰 V4A，但确认下 V4A 是否正常工作

> 硬件上限 44100 Hz / 16bit，超出范围的音源无法直接播放

> 想要高采样率，只能外接 USB DAC

[?] 手表变热了

> 充电时 3A 输入会有一定发热，34~42°C 正常

> 超过 45°C 建议降输入上限，编辑 service.sh：

echo 3000000 改为 echo 1500000

> 温控阈值模块完全没动，厂商保护策略仍然生效

[?] 闹钟 / 定时器失效

> 目前测试正常，如遇到偶发问题先重启

> 若持续失效，尝试把 persist.sys.heartbeat.enable=0 删掉（改回原厂值）

> 测试命令：

dumpsys alarm | grep deskclock

[?] 怎么彻底卸载 / 恢复原状

> Root 管理器 → 模块 → 删除本模块

> 重启设备

> 模块内置 uninstall.sh，会自动清除所有 persist 属性

> 如果发现虚标回来了，这是正常现象——说明模块已经清理干净

[?] 可以给别的机型刷吗

只适用 SL8541E / SC9832E + 和顺成方案。

> 其他方案刷入可能属性名对不上，部分功能无效
